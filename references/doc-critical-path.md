# Template: CRITICAL-PATH

The shortest line to the first real outcome - first revenue, first user, first proof. Strips the plan down to only what actually gates that outcome. Tier 3 (or any time the plan has grown and you need to find the true bottleneck).

## Questions it must answer

- What is the first real outcome we're driving to?
- Which track is actually ON that path, and which is parallel-but-not-on-it?
- What gates what?
- What's the honest path to that outcome?
- What can start today, on every track?

## Required sections

- `## The key truth` - the one insight about what really gates the outcome (often not what you'd assume).
- `## The tracks` - which are on the critical path, which run in parallel and are NOT first-outcome-gating.
- `## The seam` - where the parallel tracks meet.
- `## What gates what`.
- `## The path to <first outcome>` - the ordered line.
- `## Start-now actions` - today, on every track.

## Good vs slop

Good: it's honest about which work feels productive but does not move the first outcome closer. Slop: relabeling the full implementation plan as "critical path" without cutting a single thing.
